# Content: sources and rules

Every piece of text in the app is listed here with where it came from. Keep this file
accurate. It is the project's record that the content is free of third-party copyright.

| File | What | Source | Rights |
|---|---|---|---|
| `sanskrit.json` | Sanskrit text of all 701 verses + speaker lines | The ancient text. Digital copy imported by `tool/import_sanskrit.py` from github.com/gita/gita (Sanskrit field only), with typos fixed against standard printed editions | Public domain. The digital source is released under The Unlicense |
| `sanskrit.json` → `iast` | Pronunciation in Roman letters | Generated by `tool/iast.py` (written for this project) | Generated |
| `translations/chNN.json` | English and Hindi translations, simple meanings, notes | Written for this project directly from the Sanskrit; AI-assisted drafts, checked with `tool/check_similarity.py`, then reviewed by a named scholar | Original to this project |
| `chapters.json` | Chapter titles and summaries | Written for this project. The Sanskrit chapter names are the traditional colophon titles | Original / public domain |
| `learn.json` | Speaker labels, "Start here" text, glossary | Written for this project | Original |

## Rules

1. Never copy, paraphrase or paste text from a published translation or commentary. That
   includes asking an AI to "rephrase" one.
2. Reference translations may be used **only** as comparison data for
   `tool/check_similarity.py`. Keep them in `reference/`, which is git-ignored, and never
   commit them.
3. Every new verse starts as `"status": "draft"`. A verse becomes `"reviewed"` only after
   both of these are done:
   - the similarity check reports 0 flags;
   - a scholar has checked it, and their name is recorded in `"reviewedBy"`.
4. Store releases are built with `python3 tool/build_content.py --reviewed-only`.
5. After editing anything here, run `python3 tool/build_content.py` and commit the
   regenerated `assets/content/gita.json`. CI fails if you forget.
