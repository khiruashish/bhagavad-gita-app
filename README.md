# Gita for Everyone · सबके लिए गीता

A free, offline Bhagavad Gita app for Android and iOS, made for people who are new to the
Gita. No ads, no account, no tracking.

- **One verse a day.** Day 1 is the first verse, Day 2 the next, and so on.
- **Sanskrit, Hindi and English** for every verse, with a pronunciation guide and a short
  "in simple words" explanation.
- **Listen** to the Sanskrit, Hindi or English, read by your phone's own voice.
- **All 18 chapters** with plain summaries, a beginner's "Start here" guide and a glossary.
- **Hindi or English interface**, dark mode, adjustable text size.
- **Fully offline:** no internet permission and no data collected.

All content is free of third-party copyright:
- the Sanskrit is public domain;
- the pronunciation guide is generated by our own script;
- translations and explanations are original to this project.

See [content/README.md](content/README.md).

> **Status:** 571 of 701 verses have draft translations (Chapters 1–15).
> All translations need scholar review before release. See [docs/GUIDE.md](docs/GUIDE.md).

## Run it

Requires Flutter (stable) and Python 3.

```bash
flutter pub get
flutter run                       # Android emulator/phone or iOS simulator (macOS)
flutter test                      # app tests
python3 -m unittest discover -s tool   # content tool tests
```

## Work on content

```bash
# after editing anything in content/
python3 tool/build_content.py                   # validates and writes assets/content/gita.json
python3 tool/check_similarity.py reference/     # compare drafts with reference translations (kept outside git)
python3 tool/build_content.py --reviewed-only   # for store releases: reviewed verses only
```

## Build for release

```bash
python3 tool/build_content.py --reviewed-only
flutter build appbundle --release --obfuscate --split-debug-info=build/symbols   # Google Play
flutter build ipa --release --obfuscate --split-debug-info=build/symbols         # App Store (macOS)
```

Signing, store listings and testing are covered in [docs/GUIDE.md](docs/GUIDE.md).

## Project layout

```
lib/
  main.dart                      loads content + settings, starts the app
  src/app.dart, app_scope.dart   theme, text scaling, dependency scope
  src/content/models.dart        verse/chapter models, parsing
  src/daily/daily_plan.dart      Day N -> verse logic
  src/settings/                  preferences (on-device only)
  src/audio/verse_speaker.dart   text-to-speech behind an interface
  src/l10n/strings.dart          interface text in English and Hindi
  src/ui/                        Today, Chapters, reader, Start here, Settings
content/                         source content (see content/README.md)
assets/content/gita.json         generated; the only file the app loads
tool/                            content import, IAST, build, similarity check, tests
test/                            unit and widget tests
```
